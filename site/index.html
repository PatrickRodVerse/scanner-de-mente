Set up the app

  1. Download and run Scanner-de-Mente-Setup-x64.exe on Windows 10 or 11 x64. Python and dependencies are included.
  2. Open Scanner de Mente from the Start menu or desktop. Approve the Microsoft runtime installer if requested during setup.
  3. Run an experiment in the browser tab that opens. The first run downloads the GPT‑2 checkpoint.

Allow a few gigabytes of disk space and 3 GiB of available RAM for an experiment. Internet is needed for the first model download (about 550 MB). The installer is unsigned; its SHA-256 checksum is on the release page. View the open source code (MIT).

Change the prompts

Start with the example, then edit the reference and changed prompts. Keep the same token count in both prompts and choose two distinct names that each tokenize to one token. Run the comparison, inspect a block and token in the heatmap, then export the measured result as JSON.

What we changed

An internal state is a vector of numbers the model keeps at a token position. We copy the reference state of the changed name after block 6. To test whether the effect depends on the final token, we hold that token’s state after block 8 at its value in the changed prompt. Block numbers start at zero.

What the evidence supports

In these prompt pairs, much of the effect of restoring the name depends on the update at the final token. We intervene on the entire vector at each position. The roles of individual attention heads and paths are still open questions.

View controls and reproduce on CPU

A logit is a score before probabilities are calculated. The effect is the difference between a restoration and its matching control. Recovery scales that change against the gap between the two prompts. Copying the last state of the reference prompt at the final block recovered the full gap. Holding either position without restoring the name left its control score unchanged within numerical tolerance.
